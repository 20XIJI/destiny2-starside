# Verify Starside (`destiny2-starside`)

Starside is a zero-dependency static web application (`site/`) generated by Python scripts (`tools/`) from markdown and JSON sources (`references/`, `data/`), paired with a CloudBase Node cloud function (`functions/api/`).

Before driving any UI path, consult the [feature verification map](./features/README.md) and follow the matching feature recipe.

## Launch

Always verify the offline build and regression gates first, then launch an isolated HTTP server bound to `127.0.0.1` on an ephemeral port and open an isolated `playwright-cli` session from a scratchpad directory (never from the repo root, so `.playwright-cli/` logs do not pollute `git status`):

```bash
REPO_ROOT="/Users/eliver/code/MISC/destiny2-starside"
cd "$REPO_ROOT"
npm run build
npm test

RUN_ID="ss-$(date +%s)"
SCRATCH="/tmp/starside-verify-$RUN_ID"
EVIDENCE_DIR="$SCRATCH/evidence"
mkdir -p "$SCRATCH" "$EVIDENCE_DIR"
cd "$SCRATCH"

PORT=$(python3 -c 'import socket;s=socket.socket();s.bind(("127.0.0.1",0));print(s.getsockname()[1]);s.close()')
echo "$PORT" > "$SCRATCH/port"
python3 -m http.server "$PORT" -b 127.0.0.1 -d "$REPO_ROOT/site" >"$SCRATCH/http.log" 2>&1 &
echo $! > "$SCRATCH/http.pid"

playwright-cli -s="$RUN_ID" open
playwright-cli -s="$RUN_ID" resize 1440 900
```

Wait until the server answers and serves the Starside home page before driving (avoid piping `curl` to `grep -q` under `pipefail`, which exits 23 when `grep -q` closes the pipe early):

```bash
python3 -c 'import urllib.request; assert "Starside · Destiny 2 中文资料台" in urllib.request.urlopen("http://127.0.0.1:'"$PORT"'/index.html").read().decode()'
```

## Doctor

Run this read-only check before driving or whenever behavior looks wrong:

```bash
PORT=$(cat "$SCRATCH/port")
PID=$(cat "$SCRATCH/http.pid")
kill -0 "$PID"
python3 -c 'import urllib.request; assert "Starside · Destiny 2 中文资料台" in urllib.request.urlopen("http://127.0.0.1:'"$PORT"'/index.html").read().decode()'
playwright-cli -s="$RUN_ID" --raw eval "location.href"
git -C "$REPO_ROOT" status -s
```

Doctor passes when:
1. `$PID` is alive and owns `127.0.0.1:$PORT`.
2. `http://127.0.0.1:$PORT/index.html` returns the Starside `<title>`.
3. The `playwright-cli` session `$RUN_ID` responds to `eval`.
4. `git status -s` in `$REPO_ROOT` has no untracked `.playwright-cli/` artifacts.

Never drive a shared port (`3000`) or an existing browser session you did not start.

## Drive

Drive the browser through `playwright-cli -s="$RUN_ID"` from inside `$SCRATCH`:

- **Explicit paths only:** `serve.json` disables `cleanUrls`. Always navigate to full paths ending in `/index.html` (e.g., `http://127.0.0.1:$PORT/weapons/index.html`).
- **Stub external CloudBase calls before navigation:** pages fire a visitor counter request to `https://dea-mods-d1g0j2rile2323f73.service.tcloudbase.com/api` and build pages query `?a=likes`. When testing offline or asserting network-dependent UI (likes, submission, in-place edit), intercept the API route first:
  ```bash
  playwright-cli -s="$RUN_ID" route "https://*.service.tcloudbase.com/api*" --body='{"today":12,"total":3456,"likes":{"s29_5xzv1dm6-hunter":9}}'
  ```
- **Prefer stable handles:**
  - Global search (Home): `getByRole('combobox', { name: '搜索全站资料' })`, `#hero-hits`, `.hero-search .tool-count`
  - Reference page toolbar: `.toolbar .tool-search`, `.toolbar .tool-count`, `.toolbar .tool-chips a.chip`, `.toolbar .tool-chips button.toggle`
  - Weapons armory (`/weapons/index.html`): `.wpn-scope [data-act="scope"]`, `.wpn-input`, `.wpn-count`, `.wpn-quick [data-act="preset"]`, `.wpn-conds [data-act="unpill"]`, `[data-act="open"]`, `[data-act="perk"]`, `[data-act="statsmode"]`
  - Builds directory (`/builds/index.html`): `[data-facet="职业"] button`, `[data-facet="场景"] button`, `[data-facet="强度"] button`, `[data-facet-tuck] details.drop`
  - Build forge (`/builds/new/index.html`): `[data-key="配装名"]`, `[data-key="推荐人"]`, `[data-slot]`, `#src`, `#out`, `#imp`, `#in`, `#send`
- **Scrolling and `content-visibility: auto`:** `site.css` sets `scroll-behavior: smooth` on `html`, and long pages (`artifact-mods/`, `armor-sets/`, `builds/sets/`) apply `content-visibility: auto` to off-screen rows. Always scroll with `behavior: 'instant'` before reading layout or taking a viewport screenshot:
  ```bash
  playwright-cli -s="$RUN_ID" --raw eval "window.scrollTo({top: 2400, behavior: 'instant'}); window.scrollY"
  ```

## Evidence

Store all verification proof in `$EVIDENCE_DIR` (outside `$SCRATCH/.playwright-cli/` so it survives browser teardown):

- **UI proof:** capture both a structural ARIA snapshot and a viewport screenshot at `1440×900` showing the user action and resulting state (pass a path relative to `$SCRATCH`, i.e., `evidence/<name>`, because `playwright-cli` restricts `--filename` to the current working directory):
  ```bash
  playwright-cli -s="$RUN_ID" snapshot --filename="evidence/<feature>-<step>.yaml"
  playwright-cli -s="$RUN_ID" screenshot --filename="evidence/<feature>-<step>.png"
  ```
- **Never use `--full-page` or tall element screenshots:** off-screen `.mod-row` and `.set-bonuses` elements have `content-visibility: auto` and render as blank boxes in full-page captures; element screenshots composite sticky headers (`.site-head`, `.art-bar`) across the middle of the image. Scroll to the target position with `behavior: 'instant'` and capture the viewport.
- **State and side-effect proof:** pair visual captures with `playwright-cli -s="$RUN_ID" --raw eval "<expr>"` assertions (URL query/hash, DOM counts, computed styles, or exported markdown in `#out`).
- **Build & gate proof:** record the exit code and summary output of `npm run build` and `npm test` (plus `ruff check tools/*.py` and `pyright tools/*.py` when Python files changed).
- **Dry-run boundary note:** `python3 tools/deploy.py --dry-run` skips `sync.py` and does not upload to CloudBase, whereas `python3 tools/deploy.py` without `--dry-run` mutates remote CloudBase storage and database state. Never run `deploy.py` without `--dry-run` during verification.

## Cleanup

Tear down the browser session and the HTTP server by the exact session name and PID started by this run. Never run `close-all`, `kill-all`, or `pkill`, and never delete `$EVIDENCE_DIR`:

```bash
playwright-cli -s="$RUN_ID" close
if [ -f "$SCRATCH/http.pid" ]; then
  kill "$(cat "$SCRATCH/http.pid")" 2>/dev/null || true
  rm -f "$SCRATCH/http.pid"
fi
rm -rf "$SCRATCH/.playwright-cli"
playwright-cli list
ls -la "$EVIDENCE_DIR"
```

Confirm after cleanup that:
1. The session `$RUN_ID` is no longer listed in `playwright-cli list`.
2. All proof artifacts in `$EVIDENCE_DIR` still exist and are non-empty.
3. `git -C "$REPO_ROOT" status -s` is clean of verification scratch files.

## Helpers

No external helper binary is required. The one-liner below runs a complete server + session teardown safely on exit when prototyping a one-off check in `$SCRATCH`:

```bash
trap 'playwright-cli -s="$RUN_ID" close >/dev/null 2>&1 || true; [ -f "$SCRATCH/http.pid" ] && kill "$(cat "$SCRATCH/http.pid")" 2>/dev/null || true' EXIT
```
