# Starside · 命运 2 中文资料台

**线上访问：[https://starside.work](https://starside.work)**

Starside 是《命运 2》（Destiny 2）的简体中文资料与配装网站，整理了全武器词条模拟、当前赛季配装方案，以及职业技能、武器特性、护甲模组、伤害加成与突袭副本的实测数据。

全站采用游戏内官方简体中文译名，并用固定颜色区分元素与机制：电弧、烈日、虚空、冰影、缚丝、棱镜六大分支，以及异域装备、护甲充能、能量球、增益、减益与不同级别的战斗人员一目了然。资料页中方括号如 `[10%]` 代表 PvP 数值，`?` 代表尚待实测确认的条目。

---

## 全站搜索与实时轮换

- **全站搜索**：在首页搜索框输入简体中文、英文原名、全拼或拼音首字母，即可搜出全站资料词条与装备库物品；按 `/` 或 `⌘K` 聚焦搜索框，`↑` `↓` 选择，`Enter` 直达对应位置。
- **实时轮换栏**：首页顶部常驻显示本周轮换突袭、本周轮换地牢、当前与下一小时扭曲星球目的地，以及本周永恒之诗光尘商品与仄（九芒星商人）在售列表。

## 核心功能

### [装备库](https://starside.work/weapons/index.html)

收录 **1,867** 把武器、**135** 件异域护甲（含 **36** 枚异域职业物品之灵）与 **56** 套护甲套装：

- **快捷筛选与 DIM 语法**：可按槽位、枪型、元素、反勇士类型一键筛选，也可直接输入 `is:exotic`、`is:craftable`、`perk:`、`tier:`、`season:`、`foundry:`、`breaker:` 等 DIM 过滤指令。
- **自选词条与属性计算**：点选枪管、弹匣、第 3/4 栏特性、武器模组、大师杰作与 T1–T5 武器阶级，实时算出面板属性、射程衰减距离（米）、填装与开镜耗时（秒）、每次拾取弹药砖的回复量及特性触发后的加成。
- **PvP 击杀耗时（TTK）计算**：根据当前所选词条，实时算出最优击杀时间、需要几发暴击与身体命中、最大致死距离，以及触发增伤词条后的击杀表现。
- **双作者评级与推荐词条**：同屏展示 Aegis 与小棒猪-LGpig 的梯队评级、适用场景与推荐词条标识，并列出该武器当前赛季可用的神器模组与相关配装。

### [配装系统](https://starside.work/builds/index.html)

- **[配装推荐](https://starside.work/builds/index.html)**：按高难宗师、日常速刷、首领输出等场景及泰坦、猎人、术士三职业分类，完整展示超能、技能、星相、碎片、武器、护甲模组、神器模组、属性加点优先级与输出循环；鼠标悬停在任意装备或技能图标上即可直接查看实测数值。
- **[配装合集](https://starside.work/builds/sets/index.html)**：将同一角色在整座突袭或不同关卡下的多套配装收在同一页，点击左侧目录即可切换对照。
- **[配装工具](https://starside.work/builds/new/index.html) & [合集工具](https://starside.work/builds/new/set/index.html)**：在线点选职业分支、武器词条、护甲模组与赛季神器，编写并提交自己的配装方案。
- **一键导入 DIM 与生成长图**：所有配装页面均可点击「导入 DIM」直接跳转到 DIM 套用配装，或点击「生成图片」保存高清配装长图。
