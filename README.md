# Starside · 命运 2 中文资料台

**线上访问：[https://starside.work](https://starside.work)**

Starside 是《命运 2》（Destiny 2）的简体中文资料与配装站点，收录全量武器与护甲装备库、场景配装方案，以及职业分支、武器特性、护甲模组、伤害倍率与副本机制的实测速查表。

全站统一对照游戏内简体中文译名与语义着色：电弧、烈日、虚空、冰影、缚丝、棱镜六种元素，以及异域装备、护甲充能、能量球、增益、减益与三档战斗人员各自对应固定色号。资料页中的方括号如 `[10%]` 标示 PvP 数值，`?` 标示尚待实测核实的条目。

---

## 全站检索与实时轮换

- **全站搜索**：首页搜索框检索全站资料页条目与装备库物品，支持简体中文、英文原名、全拼与拼音首字母，按 `/` 或 `⌘K` 聚焦，`↑` `↓` 选行，`Enter` 直达锚点。
- **实时轮换条**：首屏常驻展示本周轮换突袭、本周轮换地牢、当前与下一小时扭曲星球目的地，以及当周永恒之诗光尘优惠与仄在售列表。

## 核心功能

### [装备库](https://starside.work/weapons/index.html)

收录 **1,867** 把武器、**135** 件异域护甲（含 **36** 枚异域职业物品之灵）与 **56** 套护甲套装：

- **DIM 语法检索**：支持 `is:exotic`、`is:craftable`、`perk:`、`tier:`、`season:`、`foundry:`、`breaker:` 等过滤指令，配合槽位、枪型、元素与反勇士芯片快速筛选。
- **词条点选与属性实时模拟**：在详情面板点选枪管、弹匣、特性、模组、大师杰作与 T1–T5 武器阶级，实时重算六维属性、射程衰减米数、填装与开镜秒数、弹药块拾取量及主动增益效果。
- **PvP 数据板**：按当前配装实时计算最优击杀时间（TTK）、暴击与身体命中组合、致死距离及增伤词条触发后的击杀阈值。
- **双作者评级光圈**：同屏对照 Aegis（Endgame Analysis）与小棒猪-LGpig 的梯队评级、场景定位与推荐词条光圈，并关联当前赛季可用神器模组与站内配装方案。

### [配装系统](https://starside.work/builds/index.html)

- **[配装推荐](https://starside.work/builds/index.html)**：按终局高难、日常速刷、团本输出等场景与泰坦、猎人、术士三职业分类，展示超能、技能、星相、碎片、武器、护甲模组、神器模组、六维属性优先级与机制循环说明；鼠标悬停任意装备格即可查看站内实测机制。
- **[配装合集](https://starside.work/builds/sets/index.html)**：同一角色在多场遭遇战或不同环境下的成套配装合为一页，按目录切换对照。
- **[配装工具](https://starside.work/builds/new/index.html) & [合集工具](https://starside.work/builds/new/set/index.html)**：可视化点选子职业、武器词条、护甲模组与赛季神器，支持在线投稿。
- **导入 DIM 与生成长图**：任意配装详情页与合集页均支持「导入 DIM」一键跳转应用配装，或点击「生成图片」导出高清配装长图。
