# 棱镜光剑猎

场景：宗师终极
定位：通用
分支：棱镜
类别：meta
核心：英勇利刃

## 审核意见

也可以带焕光闪身+勇气琢面的组合
有光剑的情况下裁决定论的伤害并没有那么重要了,可以考虑带工具枪或白弹
没有圣贤2王冠2可以用vog4,但就只能绑定光能蜘蛛头了

## 注解

光剑选择：进攻形态+冲击核心+超利刃
这套配装通过格挡伤害和飞升获取增幅，通过使用手雷获取织造铠甲，通过冲击核心命中获取恢复。圣贤套给的手雷及职业能量能保证职业技能和手雷的高效覆盖，光剑作为动能武器提供的高额超凡进度条可以频繁开启超凡，生存和清杂能力进一步提升。在有绿弹之后使用光剑复读三左一右连招，配合进攻形态和动能合成神器模组拥有无限弹药。对于远点的战斗人员，翻新+狙击手冥想也能高效处理。在高难本中注意远离自爆怪，频繁使用烟雾弹致盲战斗人员控场，避免承受太多伤害，并优先处理高威胁的战斗人员

这套装备有几个门槛：1.试炼的双重王冠2件套；2.vog的裁决定论
六维可以用护甲模组来凑，护甲主要堆武器属性
二号位若没有裁决定论随意携带一把晕势不可挡的绿弹用于补伤害即可，如果无弹药开局二号位也可以带白弹武器和绿弹终结来启动
如果实在没有双重王冠，可以选择4vog套 / 2圣贤2空降灭火，彪悍环境实在回不上血也可以带虫骸+至纯或者虫骸+复兴
职业金也可以选择复兴曲腹蛛组合，手雷带沐浴雷，生存更加变态
