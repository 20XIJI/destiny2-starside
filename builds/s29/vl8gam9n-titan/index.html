# 炸死所有猪

推荐人：咕咕猪子

更新：2026.9.9
场景：日常
分支：烈日
强度：创意

## 审核意见

手雷未击杀目标/手雷击杀目标数量和质量较低时，比较依赖焰灵所提供的技能回转，需要使用者频繁跑位。
