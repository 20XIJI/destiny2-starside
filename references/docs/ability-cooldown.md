## 技能能量生成

技能能量的整块获取通常由各类技能的基础冷却决定，{pickup|职业技能}、手雷技能、近战技能与超能技能都算在内。

终愿赛季改变了「按百分比给一整块技能能量」这类效果与整块系数的交互方式，{perk|爆破专家}、{exotic|投弹手}、充沛、动量转移都属于这一类。
超能不受整块修正影响，不过多数持续型超能在造成伤害时会获得更多能量。

整块系数会压低按百分比计的能量获取，手雷与职业技能最低到 0.5×，近战技能最低到 0.6×。

整块系数按冷却分档，不是连续函数——冷却相近的技能共用一个系数。三类技能各走一套档位：手雷五档、近战五档、{pickup|职业技能}三档，彼此不通用。

除非另有说明，或某件{exotic|异域}装备与某个技能有专门交互，所有技能的能量获取都受整块能量缩放影响。

技能冷却按下式计算：

{formula|{lhs|T =}{num|C}{den|1 + S + E}}

其中 {var|T} 为实际冷却时间，{var|C} 为基础冷却时间，{var|S} 为属性加速系数，{var|E} 为额外加速系数。

## 名词解释

基础回复单位
: 一个技能拥有的回复「量」。基础回复速度由 0 属性时的冷却决定，逐个技能不同。默认为 1×，投入属性即按上表提高。

额外基础回复单位
: 由效果提供的基础回复单位，如{exotic|异界之眸}、{exotic|反转之握}。

被动倍率
: 直接乘在回复速度上的倍率。回复速度由全部基础回复单位与各自的基础回复速度相乘后合并得出。术士对手雷回复有 1.1× 倍率；掷弹兵提供 5× 手雷回复倍率，叠在{exotic|反转之握}的高基础回复单位上会得到极高的回复速度。{el-prismatic|棱镜}分支在 PvP 另有 0.85× 倍率，叠在 PvP 本身的 0.8× 之上。

回复倍率
: 表内写在每个技能那一格。它压低百分比与每秒百分比获取的效果，冷却越长的技能惩罚通常越重。只对特定技能生效的效果可能没有惩罚。{el-prismatic|棱镜}分支在 PvP 另有 0.8× 惩罚。

属性倍率
: 按对应属性缩放获得的能量，作用于百分比获取、每秒百分比获取，以及额外基础回复效果。

充能授予
: 直接给予技能充能次数的效果，不受任何倍率影响。

职业模组倍率
: 影响职业模组（轰炸手、外延、分配）所给能量的倍率。这些能量仍会再受对应技能的回复倍率影响，因而有时是双重惩罚。回复倍率为 1× 的职业技能，所授能量倍率为 0.4×，{exotic|冰瀑衣钵}除外，它是 1×；回复倍率 0.8× 的为 0.6×；回复倍率 0.5× 的为 1×，{exotic|乔木典狱官}除外，它恒为 0.4×。

每秒百分比获取
: 逐渐给予的能量，与基础回复效果无关，如火焰之歌、{exotic|真理之容}对{enemy|自己}的那一份。

百分比获取
: 立即成块给予的能量，如爆破手。
