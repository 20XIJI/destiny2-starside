# 弹药生成机制

描述：击杀生成弹药的基础百分比、技能与手雷的固定值，以及 Perk、模组、套装加成的叠加方式。
更新：2026.7.26
数据源：[DIM 社区](https://discord.com/channels/591927598255439873/1453807417430245518)的弹药生成实测{note|（链接指向 Discord 频道内页，需登录并已加入该服务器）}

## 武器弹药生成

击杀战斗人员按一个基础百分比生成弹药。这个百分比由四项决定：击杀所用的弹药类型、生成的弹药类型、战斗人员等级，以及武器的弹药生成属性。

| 弹药生成属性 | {bar-red|红血} | {bar-orange|橙血} | {bar-yellow|初级首领} |
|---|---|---|---|
| {el-kinetic|白弹} → {el-strand|绿弹} | 6%–16% | 12%–24% | 24%–50% |
| {el-kinetic|白弹} → {ammo-heavy|重弹} | 3%–8% | 6%–16% | 12%–32% |
| {el-strand|绿弹} → {el-strand|绿弹} | 3%–12% | 6%–18% | 12%–40% |
| {el-strand|绿弹} → {ammo-heavy|重弹} | 3%–8% | 6%–16% | 12%–32% |
| {ammo-heavy|重弹} → {el-strand|绿弹} | 3%–16% | 6%–24% | 12%–50% |
| {ammo-heavy|重弹} → {ammo-heavy|重弹} | 3%–4% | 6%–8% | 12%–16% |
|---|---|---|---|
| 技能 → {el-strand|绿弹} | 4% | 8% | 16% |
| 技能 → {ammo-heavy|重弹} | 4% | 8% | 16% |
| 手雷 → {el-strand|绿弹} | 6% | 12% | 24% |
| 手雷 → {ammo-heavy|重弹} | 4% | 8% | 16% |

表中的区间随武器的弹药生成属性线性变化。弹药生成属性 100 的特殊武器击杀一名{bar-orange|橙血}战斗人员，生成 18% 的{ammo-special|特殊弹药}与 16% 的{ammo-heavy|威能弹药}，两者都落在各自区间的上限。

三档战斗人员之间大致成倍数关系：{bar-orange|橙血}约为{bar-red|红血}的两倍，{bar-yellow|初级首领}约为四倍。记住{bar-red|红血}一列，其余两列可以推算。

## 技能弹药生成

技能生成的弹药远少于弹药生成属性合格的武器，靠技能补弹的收益有限。几乎所有技能对{bar-red|红血}、{bar-orange|橙血}、{bar-yellow|初级首领}战斗人员分别生成 4%、8%、16% 的{ammo-special|特殊弹药}与{ammo-heavy|威能弹药}。

唯一的例外是手雷：它生成{ammo-special|特殊弹药}的速度高出 50%，对三档战斗人员分别给 6%、12%、24%。{ammo-heavy|威能弹药}那一档与其他技能相同。

## 武器 Perk

光中藏弹
: {ammo-special|特殊弹药}生成系数 ×1.25{note|（当前版本存在 Bug：加成对所有武器生效，且其他武器开火不消耗层数）}。
即兴弹药
: {ammo-special|特殊弹药}生成系数 ×1.15，{ammo-heavy|威能弹药}生成系数 ×1.1。

## 护甲模组

特殊弹药搜寻者
: {ammo-special|特殊弹药}生成系数 ×1.25 | ×1.40 | ×1.50
威能弹药搜寻者
: {ammo-heavy|威能弹药}生成系数 ×1.25 | ×1.40 | ×1.50

这些加成同时装在多把武器上可以叠加，且不是逐项相乘，而是把各自的增量相加后一次作用于基础百分比。

两把枪各带一个*光中藏弹*，因上述 Bug 会同时计入两个 ×1.25；再带一把*即兴弹药*的武器，追加 ×1.15；头盔上三个*特殊弹药搜寻者*按 ×1.50 计。用带*即兴弹药*的武器击杀{bar-red|红血}战斗人员，{ammo-special|特殊弹药}生成率为：

{formula|12% × (1 + 0.5 + 0.25 + 0.25 + 0.15) = **26%**}

56 套护甲里有 10 条效果直接作用于弹药：8 条给弹药进度，2 条抬高弹药生成属性。以下只摘与弹药有关的部分，完整触发条件与其余效果见[护甲套装效果](../armor-sets/index.html)。

再补给{from|溢冰 2 件}
: 造成最后一击时 {ammo-special|特殊弹药} +20%、{ammo-heavy|威能弹药} +20%，并生成一颗含 1% 超能能量的能量球。{note|12 秒内置冷却。}

: 消灭{bar-orange|守护者}、{bar-orange|橙血}或更高级战斗人员时 {ammo-special|特殊弹药} +12%、{ammo-heavy|威能弹药} +7.5%。

: *肾上腺素充沛*激活时，{ammo-special|特殊弹药}进度按目标分档：红血 +3%，{bar-orange|橙血}或更高级 +16%，傀儡{bar-orange|橙血}或更高级 +24%，{bar-orange|守护者} +{unsure|?}%。破坏可摧毁物件与构造体同样触发，给 +16%。
年事已高{from|空降灭火 4 件}
: 对{bar-orange|橙血}或更高级战斗人员使用终结技时 {ammo-special|特殊弹药} +16%，并恢复 32 生命值。
傀儡武装{from|伟大狩猎 4 件}

能量填装{from|最后纪律 4 件}

抬高弹药生成属性：

## 注解

未充能近战把战斗人员打到终结状态后，终结不提供任何弹药能量。双特殊武器靠技能补弹这条路因此走不通。

终结的弹药生成难以复现出一致结果。目前的判断是：生成量取决于终结当下所持的武器，而不是造成终结的手段。

武器属性 200 时另有一段额外弹药量，实测接近翻倍。各武器之间异常值较多，尚未归纳出一致的公式。
